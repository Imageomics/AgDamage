# Report-out figures

These static figures were assembled for a project presentation. Most draw from the maintained metadata and analysis reports; some also use supplemental exploratory tables that are not produced by the core pipeline.

The supplemental input directory defaults to `reports/report_out_inputs/` and can be overridden with `AGDAMAGE_REPORT_INPUTS`. Depending on the figure script, the expected files are `date_only_f1.csv`, `refbalance.csv`, `refbalance2.csv`, `fifty_only.csv`, and `pixels.csv`.

The checked-in PNGs are retained as presentation artifacts. Treat the analysis directories indexed by [`../README.md`](../README.md) as the maintained, end-to-end reproducible results.
